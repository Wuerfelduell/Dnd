# Grafikwünsche CJ

Keine Grafik wird in diesem Textpaket erzeugt. `platzhalter` benennt nur eine vorhandene Vorschauquelle; Charakterdaten verwenden bis dahin ihre Palette. Portrait-Platzhalter: erste 64×64-Zelle des angegebenen Emotions-Sheets. Tier- und Wetterplatzhalter sind technische Vorschauen, keine endgültigen Motive.
